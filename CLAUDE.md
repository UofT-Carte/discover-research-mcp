# discover-research-mcp

MCP server for the UofT Discover Research portal.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`UofT-Carte/discover-research-mcp`, private), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
